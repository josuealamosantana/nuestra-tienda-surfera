# Sea & Surf Center - Gran Canaria Tourism

This web application is a responsive landing page designed for a high-performance surfing school and eco-tourism center in Gran Canaria. It allows users to explore water sport activities, check training schedules, and discover local nature routes.

---

## Inspiration Source 🎨

* **Design Concept:** This project is explicitly inspired by the following web design layout found on Dribbble: [Surfing School Landing Page](https://dribbble.com)

---

## Getting Started 🚀

These instructions will give you a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites 📋

To open and inspect this project, you only need a modern web browser and a code editor.

* **Code Editor:** Visual Studio Code.
* **Browser:** Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari.
* **Formatting Rule:** Every document has been formatted using 4-space tabulations.

## Built With 🛠️

* **HTML5:** Semantic architecture (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`).
* **CSS3:** Responsive Layout built completely via Flexbox, CSS Grid, Media Queries, and Custom Properties.
* **FontAwesome:** Used exclusively as an external library to render iconography via CDN link.
